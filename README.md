# Interactive Dashboard

An Obsidian plugin that displays tasks from daily notes in an interactive dashboard.

## Features

- Displays tasks from daily notes.
- Shows multiple days in a single dashboard.
- Mark tasks as completed directly from the dashboard.
- Opens daily notes from the dashboard.
- Configurable number of displayed days.

## Settings

- Daily notes folder
- Number of days to display

## Installation

Install from Obsidian Community Plugins.
